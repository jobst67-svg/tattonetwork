# Tattoo Network — Crown Skull Pilot

A responsive, single-file browser prototype for the Crown Skull Tattoo pilot.

## Preview

Open `index.html` in a modern browser. Use the switch in the header to move between the customer view and studio dashboard.

## Prototype flows

- Studio profile and gallery preview
- Customer appointment and photo inquiry form
- Spontaneous availability slots
- Studio calendar and appointment overview
- Customer list with per-appointment deposit status
- Studio profile editing mockup

## Prototype scope

This is a front-end mockup with sample data. Forms, uploaded files, messages, bookings, notifications, and deposit tracking are not persisted or connected to external services yet.
